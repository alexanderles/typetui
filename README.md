A terminal-based typing test application built with Rust using [Ratatui](https://ratatui.rs/).

## Install and Run Locally

### Prerequisites

Make sure you have Rust and Cargo installed. If not, install them from [rustup.rs](https://rustup.rs/).

### Clone the Repository

Clone this repository to your local machine:

```bash
git clone https://github.com/alexanderles/typetui.git && cd typetui
```

### Run

To run the application directly:

```bash
cargo run
```
